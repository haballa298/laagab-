# لعگابْ 🦅 2.3 — دليل التشغيل

**للاستعمال الداخلي — الحرس الوطني الموريتاني**
تصميم وتطوير: Lieutenant Abderrahman Haballa

---

## ما الجديد في 2.3

- **التحكم بالخادم من الهاتف:** لوحة تحكم كاملة داخل التطبيق (المحادثة ← 🎛️ لوحة التحكم، أو الإعدادات ← لوحة التحكم).
- **تهيئة أول مرة من الهاتف:** لم تعد تحتاج إلى أوامر لإنشاء حساب القائد.
- **حفظ الخرائط داخل التطبيق:** زر ⬇️ على الخريطة يحفظ المنطقة الظاهرة لتعمل دون إنترنت، مع قائمة بالمناطق المحفوظة.
- **واجهة دخول جديدة** بشعار الحرس الوطني، وشعار جديد للتطبيق.
- **الوضع المبسّط** ودليل استعمال سريع عند أول فتح.

---

## 1. ما تحتاجه

- **جهاز يعمل كخادم:** حاسوب (Windows أو Linux) أو حاسوب صغير مثل Raspberry Pi، متصل بشبكة الحرس.
  ⚠️ الآيفون لا يستطيع تشغيل الخادم بنفسه، لكنك **تتحكم بكل شيء من الآيفون** بعد التشغيل.
- **Node.js** الإصدار 18 أو أحدث (من nodejs.org). لا يحتاج أي مكتبة إضافية.
- **شهادة HTTPS** (انظر الفقرة 4). بدونها لا يعمل تحديد الموقع ولا التثبيت على الآيفون.

## 2. التشغيل (مرة واحدة)

1. انسخ المجلد `laagab` كاملًا إلى جهاز الخادم.
2. شغّل الخادم:
   - **Windows:** انقر مرتين على `start-windows.bat`
   - **Linux:** `./start-linux.sh`
3. تظهر على الشاشة:
   - **عناوين الخادم** (مثل `https://192.168.1.10:8443`)
   - **رمز التهيئة** من 6 أرقام (محفوظ أيضًا في `data/setup-code.txt`)

## 3. التهيئة من الهاتف

1. افتح عنوان الخادم في **Safari** على الآيفون.
2. «مشاركة ← إضافة إلى الشاشة الرئيسية».
3. افتح التطبيق ← **المحادثة** ← تظهر «تهيئة الخادم لأول مرة».
4. أدخل **رمز التهيئة** واختر اسم المستخدم وكلمة المرور ← «إنشاء حساب القائد».
5. تنتقل مباشرة إلى **لوحة التحكم**.

## 4. لوحة التحكم بالخادم (من الهاتف)

| الميزة | ما تفعله |
|---|---|
| حالة الخادم | المتصلون الآن، المواقع، الرسائل، مدة التشغيل |
| عنوان الخادم | نسخ أو مشاركة العنوان مع العناصر (واتساب…) |
| 📣 بلاغ لكل الوحدات | رسالة تظهر فورًا عند الجميع مع تنبيه |
| ＋ إضافة مستخدم | كلمة مرور تُولَّد تلقائيًا، وزر لمشاركة بيانات الدخول |
| تعديل مستخدم | الاسم، الوحدة، الصلاحية، تغيير كلمة المرور، قطع الاتصال، إيقاف الحساب، الحذف |
| عرض الوحدات على الخريطة | مواقع العناصر الذين فعّلوا «مشاركة موقعي» |
| الصيانة | اسم الخادم، مدة الدخول، مدة ظهور المواقع، نسخة احتياطية، استرجاع، مسح المواقع أو المحادثات |

- يبقى دائمًا مسؤول واحد على الأقل (لا يمكن حذفه أو إيقافه).
- الحساب الموقوف يُقطع اتصاله فورًا ولا يستطيع الدخول حتى تعيد تفعيله.

## 5. شهادة HTTPS

**الأفضل:** شهادة يصدرها قسم المعلوماتية لاسم الخادم (مثل `laagab.garde.mr`). ضع الملفين في:
```
certs/server.key
certs/server.crt
```
**للتجربة:** شهادة موقّعة ذاتيًا (على الخادم):
```
mkdir certs
openssl req -x509 -newkey rsa:2048 -nodes -days 825 \
  -keyout certs/server.key -out certs/server.crt \
  -subj "/CN=laagab.garde.local" -addext "subjectAltName=DNS:laagab.garde.local,IP:192.168.1.10"
```
ضع عنوان خادمك مكان `192.168.1.10`. ثم ثبّت الشهادة على كل آيفون وفعّل الثقة بها من:
الإعدادات ← عام ← حول ← إعدادات الثقة بالشهادات.

## 6. حفظ الخرائط دون إنترنت

1. اعرض المنطقة المطلوبة على الشاشة (قرّب أكثر = تفاصيل أدق).
2. اضغط زر **⬇️** على يمين الخريطة.
3. اختر الاسم ومستوى التفاصيل (عامة / متوسطة / دقيقة) ← «حفظ المنطقة الظاهرة».
4. **أبقِ التطبيق مفتوحًا** حتى ينتهي الحفظ (شريط التقدّم أسفل الشاشة).
5. المناطق المحفوظة في **الأدوات ← الخرائط المحفوظة**: عرضها، تحديثها، حذفها.

لا تقبل كل الخرائط الحفظ؛ استعمل «طبوغرافيا» أو «أقمار صناعية».

## 7. أوامر احتياطية (عند الحاجة فقط)

```
node server.js code             # إظهار رمز التهيئة مرة أخرى
node server.js users            # عرض المستخدمين
node server.js passwd <user>    # تغيير كلمة مرور (إن نسي المسؤول كلمته)
node server.js adduser <user> "<الاسم>" "<الوحدة>" [admin]
node server.js deluser <user>
```

## 8. ملاحظات أمنية

- كل البيانات (الحسابات والرسائل والمواقع) في مجلد `data/` على الخادم فقط. خذ نسخة احتياطية من لوحة التحكم بانتظام.
- كلمات المرور مشفّرة (scrypt)، والدخول يُقفل 15 دقيقة بعد 6 محاولات فاشلة. رمز التهيئة يعمل مرة واحدة فقط.
- الخرائط تُجلب من خوادم خارجية عند الاتصال بالإنترنت، فقد تعرف تلك الجهات المناطق المعروضة. الخرائط المحفوظة تُقرأ من الهاتف نفسه.
- انقل التطبيق من GitHub Pages العام إلى الخادم الداخلي، واجعل مستودع GitHub خاصًا.
- الإشعارات تعمل ما دام التطبيق مفتوحًا.
