# لعگاب 2.0 — دليل التنصيب على خادم الحرس الوطني

**للاستعمال الداخلي — الحرس الوطني الموريتاني**

الحزمة فيها شيئان:
- `server.js`: الخادم الداخلي. يقدّم التطبيق ويدير المحادثة بين الوحدات ومشاركة المواقع.
- `public/`: ملفات التطبيق نفسه (`index.html` و`sw.js`).

---

## 1. المتطلبات

- جهاز خادم (Linux أو Windows) متصل بشبكة الحرس.
- Node.js الإصدار 18 أو أحدث. لا يحتاج أي مكتبة إضافية.
- شهادة HTTPS. هذا شرط إلزامي: الآيفون لا يسمح بتحديد الموقع ولا بتثبيت التطبيق إلا عبر HTTPS.

## 2. نسخ الملفات

```
laagab/
├── server.js
├── config.json           ← انسخه من config.example.json
├── public/
│   ├── index.html
│   ├── sw.js
│   ├── manifest.webmanifest   ← انسخه من مستودع GitHub الحالي
│   ├── icon-192.png           ← انسخه من المستودع
│   ├── icon-512.png           ← انسخه من المستودع
│   └── apple-touch-icon.png   ← انسخه من المستودع
└── certs/
    ├── server.key
    └── server.crt
```

⚠️ **لا تنسَ** نسخ الأيقونات وملف `manifest.webmanifest` من مستودع laagab الحالي إلى مجلد `public/`. بدونها لن يعمل التطبيق دون إنترنت.

## 3. شهادة HTTPS

**الأفضل:** شهادة يصدرها قسم المعلوماتية في الحرس لاسم الخادم، مثل `laagab.garde.mr`.

**للتجربة:** شهادة موقّعة ذاتياً:
```
mkdir certs
openssl req -x509 -newkey rsa:2048 -nodes -days 825 \
  -keyout certs/server.key -out certs/server.crt \
  -subj "/CN=laagab.garde.local" -addext "subjectAltName=DNS:laagab.garde.local,IP:192.168.1.10"
```
استبدل الاسم والعنوان بعنوان خادمك. مع الشهادة الموقّعة ذاتياً، يجب تثبيتها على كل آيفون كملف تعريف ثم تفعيل الثقة بها من:
الإعدادات ← عام ← حول ← إعدادات الثقة بالشهادات.

## 4. إنشاء الحسابات

أنشئ أولاً حساب المسؤول:
```
node server.js adduser admin "القائد" "QG" admin
```
ثم أنشئ حساباً لكل فصيلة أو عنصر:
```
node server.js adduser gmo1-c1-s1 "الفصيلة 1 — السرية 1" "GMO1-C1"
node server.js adduser gmo1-c1-s2 "الفصيلة 2 — السرية 1" "GMO1-C1"
```
- اسم المستخدم: حروف لاتينية صغيرة وأرقام فقط.
- الحقل الثالث هو **اسم الوحدة**. كل من يحمل الوحدة نفسها يتشارك قناة خاصة بها.
- كلمة المرور تُطلب عند التنفيذ، ويجب أن تكون 8 أحرف على الأقل.

أوامر أخرى:
```
node server.js users            # عرض المستخدمين
node server.js passwd <user>    # تغيير كلمة مرور
node server.js deluser <user>   # حذف مستخدم
```
يستطيع المسؤول أيضاً إضافة المستخدمين وحذفهم من داخل التطبيق: المحادثة ← إدارة المستخدمين.

## 5. التشغيل

```
node server.js
```
يعمل الخادم على المنفذ 8443، ويمكن تغييره من `config.json`. لتشغيله بشكل دائم مع إعادة التشغيل التلقائي، استعمل `systemd` على Linux أو «خدمة» على Windows.

ثم يفتح كل عنصر على الآيفون الرابط `https://عنوان-الخادم:8443` في Safari، ويختار «مشاركة ← إضافة إلى الشاشة الرئيسية».

## 6. قنوات المحادثة

| القناة | من يراها |
|---|---|
| 📢 كل الوحدات | جميع المستخدمين |
| 🛡️ الوحدة · X | أعضاء الوحدة X، والمسؤولون |
| 👤 رسالة خاصة | الشخصان فقط |

داخل كل محادثة تجد:
- رسالة نصية.
- 📍 إرسال موقعي.
- 🎯 إرسال مركز الخريطة.
- 🆘 نداء استغاثة: يظهر فوراً للآخرين مع اهتزاز وزر للملاحة إلى المُرسل.

الرسائل المكتوبة دون شبكة تُحفظ وتُرسل تلقائياً عند عودة الاتصال.
«مشاركة موقعي» ترسل الموقع كل 30 ثانية تقريباً. تظهر المواقع في طبقة «مواقع الوحدات».

## 7. ملاحظات أمنية

- البيانات كلها (الرسائل والمواقع والحسابات) محفوظة في مجلد `data/` على الخادم فقط. احرص على نسخه احتياطياً وحمايته.
- كلمات المرور مشفّرة (scrypt)، والدخول يُقفل 15 دقيقة بعد 6 محاولات فاشلة.
- **الخرائط نفسها** (الأقمار الصناعية، OpenStreetMap، Esri…) تُجلب من خوادم خارجية عبر الإنترنت. هذا يعني أن تلك الجهات قد تعرف المناطق التي تُعرض على الخريطة. للسرية التامة يلزم خادم خرائط داخلي، وهذه مرحلة لاحقة.
- انقل التطبيق من GitHub Pages العام إلى هذا الخادم الداخلي، واجعل مستودع GitHub خاصاً أو احذفه.
- إشعارات الرسائل تعمل ما دام التطبيق مفتوحاً. الإشعارات والتطبيق مغلق تحتاج تطويراً إضافياً.
